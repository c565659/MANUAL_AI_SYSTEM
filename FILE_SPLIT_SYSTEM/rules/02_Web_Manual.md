# 02 网页版说明书处理规则

本文件是 `WEB_MANUAL` 分支的权威规则。目标是从原说明书拆分逻辑页面并输出一个多页 PDF，而不是制作 HTML 网站。

## 1. 输出

- 文件名：`{model}_WELCOME GUIDE.pdf`，例如 `OBC-241A_WELCOME GUIDE.pdf`。
- 一个画板对应一个保留的逻辑页面；所有画板保存为同一个多页 PDF。
- 不覆盖原稿，不输出单张超长横向 PDF，不用整页截图或栅格化代替矢量内容。

## 2. 逻辑页面分析

PDF 物理页数不等于说明书逻辑页数。一个物理页/大画板可能包含多个实际页面，已有多个画板或多个 PDF 页也必须重新核对逻辑页面。

综合页面边框、尺寸标注、裁切关系、排列、语言页码、封面和封底，记录每个逻辑页面的：来源物理页/画板、边界坐标、宽高、语言、正文页码、阅读顺序和置信依据。尺寸逐页取自当前原稿，不使用案例固定尺寸。

边界与顺序不明确时，在正式编辑前设为 `needs_review`。

## 3. 删除目标章节

删除下列章节的全部语言版本：

- `CUSTOMER SERVICE`
- `WARRANTY CERTIFICATE`
- `WARRANTY TERMS & CONDITIONS`

删除范围包括章节标题及所属文字、表格、填写线和相关图形。必须依据章节边界、层级和版面归属判断，不能只删英文标题，也不能全局搜索 `warranty` 后删除所有匹配正文。

若目标章节与有效内容同页，只删除目标章节对象；其余正文及位置保持不变，不上移、不补空、不重新排版。每个删除对象或区域都记录来源页面、边界和理由。

## 4. 空白页判定

删除原本空白的逻辑页面，以及删除目标章节后变空白的页面。只剩页码或只有页面外框而无有效内容也视为空白。

包含 Logo、二维码、有效正文或有效图形的页面不得删除。不得以“无法提取文字”作为空白判断；须检查转曲对象、嵌入/链接图像、路径和其他可见对象。

## 5. 页面群组与外观

每个保留页面独立群组。保持文字内容、字体外观、字号、颜色、图形、页面尺寸和页内相对位置。

禁止翻译、修正文案、字体替换、内容缩放、版式优化或正文页码重排。删除内容后留下的空区保持原状。

## 6. 画板与定位

按保留页面数量创建画板，尺寸分别等于对应原页面尺寸。画板按阅读顺序编号 `1..n`，从左向右单行排列，画板间距为 `0 mm`。

以记录的原页面边界为定位基准，将整页群组仅做整体平移到目标画板。不得按删除后的内容外接框居中，因为外接框会随内容删除而改变。

若画板总宽、数量或软件限制导致无法按规则建立，停止受影响步骤并报告；不得自行缩小、换行或修改间距。

## 7. 文字转曲与线框清理

识别和删除确认完成后，将所有未转曲文字转曲。若字体缺失，不得替换字体再转曲并声称外观未变；记录缺失字体和受影响对象，任务设为 `needs_review`。

删除原页面边界线框、外围尺寸说明和辅助标记。保留插图内部框线、表格线、箭头及其他有效内容线条。难以区分的线条在删除前记录并复核。

## 8. 保存与检查

在 Illustrator 中将全部结果画板保存为一个多页 PDF，保留矢量内容。输出后核对文件名、PDF 页数、每页物理尺寸、顺序、内容边界和可见完整性，并按 `06_QA.md` 记录结构检查、视觉检查和本机运行测试。
