# 08 真实对象拆分规则

本文件是 WEB_MANUAL 页面对象归属和画板定位的权威规则。

## 1. 真实对象要求

页面拆分必须移动原稿中属于该页的真实 Illustrator 对象。优先复用边界与逻辑页面匹配的已有页面级群组，不得为方便复制完整总稿。

若原稿只有一个总群组，允许遍历其直接子对象或子群组。复合路径、已有剪切组、图片、文字组及内部子结构是原子对象；不得无必要地解除复合路径、释放已有剪切蒙版或重绘。

对象归属顺序：

1. visibleBounds/geometricBounds 完全位于页面矩形内；
2. 对象中心点位于页面矩形内，且对象未明显跨越其他页面；
3. 页面外框、裁切框、尺寸线和页面间辅助对象归入辅助结构；
4. 明显跨越多个页面且无法确认归属的对象触发 needs_review，禁止复制到多个页面。

## 2. 页面群组

每个保留页面建立一个真实对象群组，只允许整体平移到目标画板；禁止缩放、旋转、重排或按删除后外接框重新居中。删除页面外框后，页面群组只能保留该页真实内容。删除章节和空白页必须删除对应真实对象，不得用蒙版隐藏。

完成后必须删除不需要页面的真实对象、原页面外框、页面外辅助标记、空群组、未使用 Symbol、脚本创建但未使用的资源和全部目标画板外无效对象。

## 3. 禁止结构

禁止完整总稿 Symbol 或副本逐页放置、完整总稿 SymbolItem/PlacedItem/Form XObject 共享、页面级完整总稿剪切蒙版、实际边界接近完整总稿的页面群组、多个页面共同引用完整总稿、逐页裁切 PDF 回导、栅格化或截图。允许保留原稿内容自身已有的内部剪切蒙版。

## 4. 画板坐标

主脚本生成前一次性计算：

`stripWidth = pageCount × pageWidth`

`startX = -stripWidth / 2`

`artboardLeft = startX + pageIndex × pageWidth`

pageIndex 从 0 开始。必须验证全部画板坐标在 Illustrator 允许范围内。若超限，在调用主脚本前设 needs_review；不得先从 0 向右创建后再改脚本，不得缩小页面、换行或改变 0 mm 间距。
