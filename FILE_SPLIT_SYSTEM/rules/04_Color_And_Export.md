# 04 颜色与导出规则

本文件是两个分支的颜色保持与格式转换权威规则。

## 1. 原稿颜色

在 Illustrator 文档中保持原稿颜色、文档颜色模式和颜色配置，不擅自改色，不因最终 PNG 使用 RGB 而预先将整个文档转换为 RGB。

不得用屏幕取色、近似 RGB、估算 CMYK 或案例截图颜色替代原稿色样。颜色检查要区分对象填色、描边、渐变、透明度、叠印、专色及色调值。

## 2. 2286C 专色

包装绿色使用原稿中已核实的 `2286C` 专色定义，并保留专色属性与对象原有色调值。不得替换为 `#7cbd27`、近似 RGB 绿色或自行估算的 CMYK 值。

新建底板需要与绿色面一致时，只能复用原稿中已核实的 `2286C` 专色色样。验证需同时检查色样类型为专色、定义存在且对象引用正确；不能只按色样名称猜测。

若原稿缺少该专色定义、只有外观近似颜色、存在多个冲突的同名色样，或实际颜色与规定冲突：

1. 不静默重着色任何原稿对象。
2. 记录色样名称、类型、定义、色调和受影响对象。
3. 将任务设为 `needs_review`，等待用户或已批准颜色标准确认。

## 3. PDF 导出

`WEB_MANUAL` 必须由 Illustrator 画板保存为一个多页 PDF，保持矢量对象。不得通过页面截图、整页栅格化或把全部画板压成一个超长页面生成 PDF。

记录 Illustrator/PDF 预设、页面数量、页面尺寸和是否保留矢量；若导出设置会改变颜色外观，先停止并记录。

## 4. PNG 导出

`PACKAGING_DISPLAY` 的 PNG 使用 300 ppi、白色画板外背景并包含全部保留面。PNG 格式所必需的 RGB 转换仅允许发生在导出阶段。

PNG 不支持可用于印刷分色的专色或 CMYK 文档语义，因此不得声称导出 PNG 仍“支持专色”或“保持 CMYK”。交付报告应表述为：Illustrator 源文档中的专色定义已检查/保留（若已验证），PNG 在导出时转换为 RGB。

记录导出颜色设置并检查明显偏色。屏幕 RGB 预览不能保证与实体专色印刷绝对一致。

## 5. 验收记录

颜色检查至少记录：文档颜色模式、颜色配置、关键色样定义、关键对象色样/色调、是否发生全局转换、导出设置、视觉偏色结果和未决项。无本机或无样本时填“未验证”，不能默认通过。
