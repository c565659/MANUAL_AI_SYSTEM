# 06 验收与质量检查

默认 qa.mode 为 final_only。每项记录 passed、failed、not_applicable 或 unverified 及证据。结构检查失败不得标记 qa_passed。

## 1. 通用检查

- 原稿哈希证明未覆盖原稿；未读取、套用或修改 DATABASE/。
- 状态文件存在且 job_id 可重算一致；时间与计数来自脚本。
- fast_production 必须满足 probe_count <= 1、illustrator_invocation_count = 1、retry_count = 0、export_count = 1、elapsed_seconds <= 600。
- 未生成 cropped_pages、逐页中间导出、逐页高清 PNG、中间生产渲染或外部正式文件重组。

## 2. WEB_MANUAL PDF 结构与性能

最终 PDF 必须满足：

1. 页数和逐页尺寸与预期保留逻辑页一致，页面保持矢量状态。
2. 每页只包含本页真实内容；不存在完整原稿 Symbol 实例或脚本创建的页面级完整总稿剪切蒙版。
3. 页面群组实际边界不得接近原始总稿尺寸；最终文件不得包含大量画板外隐藏对象。
4. 页面内容不得引用边界明显大于页面的共享 Form XObject。例如 140 × 210 mm 页面不得引用约 1032 × 2462 mm 的完整总稿 XObject；正常小型图标、图片和页内资源可共享。
5. 文件体积小不能替代结构和性能检查。
6. missing_fonts = 0、substituted_fonts = 0、unresolved_fonts = 0、unoutlined_text_frames = 0、outline_geometry_failures = 0。
7. PDF 保存记录必须显示 preserveEditability=false、generateThumbnails=false、optimization=true、viewAfterSaving=false，且仅保存目标画板。

允许轻量只读 PDF 结构分析；禁止用 Python或其他工具重新生成、裁切、组装或修改正式 PDF。

## 3. 有限视觉 QA

只生成一张 72 ppi 联系表，检查阅读顺序、章节/空白页删除、丢失、错位和裁切。不得逐页生成高清 PNG。只允许对最多 3 个字体风险页面做原稿与最终成品定向对比；OPF-504A 回归必须包含英语 EN11。定向检查只用于 QA，不得用于生产或重组 PDF。

## 4. PACKAGING_DISPLAY

包装验收保持不变：检查实际像素符合 300 ppi、包装面外白背景、所有面与描边无裁切/丢失/重叠、颜色外观未异常、绿色面未变白、横纵相邻面外边缘净间距为 10 mm。Illustrator 源文档中的 2286C 专色定义与引用必须验证；PNG 仅保存 RGB 外观。

## 5. 状态与报告

全部适用检查通过后才标记 qa_passed。影响正确性的未决项为 needs_review，不可恢复错误为 failed。最终报告必须显示状态文件记录的真实墙钟耗时、Illustrator 执行耗时、PDF/PNG 保存耗时和 QA 耗时；禁止模型填写“约几分钟”等估计值。
