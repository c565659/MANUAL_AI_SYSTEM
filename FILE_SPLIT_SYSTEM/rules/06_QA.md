# 06 验收与质量检查

本文件是验收项、证据和状态判定的权威规则。每项记录 `passed`、`failed`、`not_applicable` 或 `unverified`，并附证据；没有样本或本机环境时必须使用 `unverified`。

## 1. 记录层次

分别记录，不得互相替代：

- 结构检查：对象、群组、画板、尺寸、色样、页数、像素等可测结构。
- 视觉检查：裁切、丢失、重叠、方向、偏色和外观一致性。
- 本机运行测试：Illustrator 版本、脚本接口、弹窗、保存和导出是否真实执行。

## 2. 分类通用检查

- 分类基于内容和结构，而非仅文件名或扩展名。
- 原稿、参考成品和辅助资源的角色正确。
- 型号由正文和文件名交叉确认，可追溯且未误用日期、尺寸或电池型号。
- 每个输入的判断依据、不确定项和后续分支已记录。
- 原稿哈希在处理前后符合“未改动”要求。
- 未读取或套用 `DATABASE/` 的原制作模板。

## 3. WEB_MANUAL

- 三个指定章节的所有语言版本均已删除，且删除范围属于章节内容。
- 混合页面的其他正文完整保留且位置未移动。
- 原空白页、删除后空白页、只剩页码页均已删除；含 Logo、二维码或有效图形的页面未误删。
- 保留页数量、逐页尺寸、语言分组与阅读顺序正确。
- 每页是独立群组，页内内容未缩放、重排、翻译或替换字体。
- 画板编号 `1..n`，从左至右单行，间距 `0 mm`。
- 所有需要转曲的文字已转曲，且没有字体替换。
- 原页面外框、外围尺寸和辅助标记已删除；内部表格线、箭头和图形线条保留。
- 输出是命名正确的一个多页矢量 PDF，而非超长单页或截图 PDF。
- PDF 页数、每页物理尺寸和视觉完整性复核通过。

## 4. PACKAGING_DISPLAY

- 正式主稿识别正确，UV 副稿、独立刀模副稿和工艺辅助内容已删除。
- 所有有信息的包装面完整保留；无信息折翼、粘口和辅助结构已删除。
- 跨面对象无丢失、无重复。
- 每面底板尺寸等于原面尺寸，有描边，且与该面内容独立群组。
- 原刀模线和折线已删除，新底板描边保留。
- 各面仅平移，大小、方向、文字朝向和颜色保持原稿。
- 横向与纵向相邻面的边缘净间距均为 `10 mm`，无重叠。
- 绿色面在 Illustrator 文档中仍引用核实的 `2286C` 专色及正确色调；没有近似 RGB/CMYK 替换。
- 输出是一张命名正确、白色外部背景、300 ppi 的 PNG。
- 画板完整包含全部面和描边；画布外边距、描边线宽的实际采用值及依据已记录。
- 按画板物理尺寸计算的期望像素与实际像素一致，无裁切、丢失或重叠。

## 5. 状态门槛

完成导出只能标记 `exported`。所有必需结构、视觉和本机运行项目均有证据且通过后，才可标记 `qa_passed`。

存在需用户决定且影响正确性的具体事项时标记 `needs_review`；不可恢复的执行错误标记 `failed`。不能用“脚本已运行”“文件已生成”替代质量验收。
