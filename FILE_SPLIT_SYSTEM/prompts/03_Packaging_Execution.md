# PACKAGING_DISPLAY 执行提示词

```text
处理一个已分类为 PACKAGING_DISPLAY 的原包装图档，输出全部有效包装面的单张平面组合 PNG；这不是三维渲染。

参数：
- 原稿路径：<原稿路径>
- 输出目录：<输出目录>
- 可选参考文件：<路径列表或无>
- 任务记录路径：<本地任务 JSON 路径>

开始前完整读取：
- FILE_SPLIT_SYSTEM/README.md
- FILE_SPLIT_SYSTEM/rules/01_File_Classification.md
- FILE_SPLIT_SYSTEM/rules/03_Packaging_Display.md（本分支行为权威来源）
- FILE_SPLIT_SYSTEM/rules/04_Color_And_Export.md
- FILE_SPLIT_SYSTEM/rules/05_Illustrator_Execution.md
- FILE_SPLIT_SYSTEM/rules/06_QA.md
- FILE_SPLIT_SYSTEM/config/settings.json
不要读取或套用 DATABASE/ 的说明书模板。

按顺序执行：
1. 预检：核对型号和文件角色；计算原稿哈希；检查系统、Illustrator 版本、脚本接口、用户未保存文档、字体、链接、可编辑性、文档颜色模式、颜色配置、色样、输出权限和软件限制。建立原稿副本。
2. 只读分析：识别正式包装主稿与 UV 副稿、独立刀模副稿、工艺说明、尺寸标注和辅助色块。删除前用主稿刀模记录所有面的真实边界、尺寸、方向和相邻关系，不能按对象所在方向粗暴判断辅助内容。
3. 面识别：保留含文字、Logo、产品图、条码、二维码、认证标志或有效图案的面；删除无信息折翼、粘口和辅助结构。单纯大面积颜色不足以独立证明应保留。跨面对象按真实边界处理，避免丢失或重复。
4. 颜色预检：保持原稿文档颜色模式和颜色配置。绿色必须复用原稿已核实的 2286C 专色及原色调，禁止用 #7cbd27、近似 RGB 或估算 CMYK 替换。若专色缺失、只有外观色或同名定义冲突，停止并记录，不静默重着色。
5. Illustrator 编辑：在每个保留面内容下方建立同尺寸、有描边的矩形底板，并与该面内容群组。白面保持白底，绿色和其他颜色面保持原底色；不覆盖渐变、纹理、图案或多色背景。
6. 描边线宽和画布外边距若配置为 null，参考本任务已批准案例的细边框外观采用临时值并记录依据；没有可靠依据时提出确认，不得称为固定用户标准。
7. 面边界记录、底板和群组复核后，删除原刀模线、折线、UV/副稿和无效结构；保留新底板描边、正文图形、装饰线和认证标志。
8. 所有面只平移，不缩放、不旋转、不镜像，保留原文字方向。尽量保持原展开图相对关系并压缩已删结构的空区，不强制单行。水平与垂直相邻面按外边缘计算的净间距均为 10 mm，且不得重叠。
9. 画板完整包含所有面及描边。以 300 ppi、包装面外白背景导出一张 {model}_包装效果图.png。不要预先将整个 Illustrator 文档转为 RGB；RGB 转换只允许在 PNG 导出阶段发生。
10. 用画板毫米尺寸按 像素=毫米/25.4×300 核算实际像素。按 FILE_SPLIT_SYSTEM/rules/06_QA.md 分别记录结构检查、视觉检查和本机运行测试，检查裁切、丢失、重叠、方向、颜色和明显偏色。

案例修正规则：OBC-292A 参考 PNG 的旧间距不是 10 mm，不得沿用；参考 PNG 将绿色 Logo 面变白是错误参考，正式处理必须保留原稿核实的 2286C 绿色。

遇到边界、型号、专色或软件限制问题时设为 needs_review；不得自行缩小、降低 ppi、拆成多图或改色。只有全部必需 QA 有证据并通过后才标记 qa_passed。
```
