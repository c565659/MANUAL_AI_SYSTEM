## 3. 使用案例的规则

- 案例可帮助识别预期结构和常见错误，但不得覆盖权威规则。
- 不复制案例坐标、画板尺寸、页数、描边或外边距到新型号。

- 案例与当前原稿冲突时，以当前原稿和权威规则为准；影响正确性时记录并请求确认。
